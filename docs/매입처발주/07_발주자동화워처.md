# 풍림_발주자동화_워처 — 설치 및 설정 안내

## 0. 개요

```text
입력    : 없음 (1/2/3단계 원본 폴더를 감시하는 오케스트레이션 레이어 —
          자체적으로 구글시트나 엑셀 파일을 직접 읽지 않음)
출력    : 없음 (1/2/3단계 스크립트를 그대로 호출만 함, 실제 산출물은
          각 단계 자신의 완료 폴더에 그대로 생성됨)
구글시트 ID : 없음 (워처 자신은 구글시트에 직접 접근하지 않음)
            단, 1→2단계 사이에 호출하는 캐리어_발주원장_검증.py는
            풍림_매입처 관리시트(17VFCCy8UTr_UyWhnw1F1n0ZivY6G1XMeOv7VnkuQeRY)를
            읽기 전용으로 조회함
인증키 경로 : 없음 (워처 자신은 인증키 미사용)
            단, 캐리어_발주원장_검증.py는 매입처발주.py와 동일하게
            Z:\★풍림전자 사무 자동화\사무실 입고 및 AS\poonglim-0f980142b793.json 참조
ANTHROPIC_API_KEY : Windows 사용자 환경변수로만 저장, 코드에 직접 넣지 않음
                    (없어도 동작함 — 규칙 기반 체크만 적용되고 AI 체크는 생략됨)
```

**의존관계 (이전 단계)**
```text
01_매입처발주.md      — 매입처발주.py (v1.10.1) 를 그대로 호출
02_매입처발주서생성.md — 발주서생성.py (v2.6) 를 그대로 호출
03_발주원장업데이트.md — 캐리어오더번호업데이트.py (v1.3) 를 그대로 호출
```
이 문서와 아래 캐리어_발주원장_검증.py는 위 세 문서가 설명하는 스크립트들을
**한 글자도 수정하지 않고** 바깥에서 순서대로 호출·검증하는 오케스트레이션
레이어다. 01~03번 스크립트 자체의 로직 변경 사항은 이 문서가 아니라 각 문서에
기록한다.

**다음 단계 (이 문서에 의존하는 것)**
```text
없음 — 현재는 이 워처가 자동화 체인의 최상위 레이어
```

## 1. 이게 뭐 하는 건가요

지금까지:
```text
발주총괄 파일 넣기 → 매입처발주_실행.bat 더블클릭 → 발주서생성_실행.bat 더블클릭
캐리어 회신파일 넣기 → 캐리어오더번호업데이트_실행.bat 더블클릭
```

이제부터:
```text
발주총괄 파일을 원본 폴더에 넣기만 하면 됨
  → 5분 안에 자동으로 매입처발주.py 실행
  → 캐리어_발주원장_검증.py(읽기 전용, 처리키 중복·형식/완료여부 정합성/
    재고현황 건전성/원본 대비 분할 합계까지 확인) 통과 시에만
  → AI가 로그를 확인해서 이상 없으면 자동으로 발주서생성.py까지 실행
  → 이상하면 진행을 멈추고 "발주서 관리\확인이_필요합니다\" 폴더에
    "확인필요_....txt" 파일을 남김

캐리어 회신파일을 원본 폴더에 넣기만 하면 됨
  → 5분 안에 자동으로 캐리어오더번호업데이트.py 실행 및 AI 체크
```

기존 `.bat` 파일들은 그대로 남겨두면 됩니다 (혹시 수동으로 다시 돌려야 할 때
대비). 다만 **워처가 켜져 있는 동안은 같은 파일을 손으로 또 더블클릭하지
않도록** 합니다 (매입처발주.py는 동시 실행 금지 원칙이 있음 — 락파일로
보호되지만 겹치게 하지 않는 게 안전함).

## 2. 실행 방식

상시 실행되는 백그라운드 프로그램이 아니라, Windows 작업 스케줄러에 등록해서
5분 간격으로 짧게 실행되고 끝나는 방식이다. 프로세스가 죽어도 다음 스케줄에서
알아서 다시 시도되므로 관리 부담이 적다.

---

## 3. 발주서 관리 폴더 (와이프님 전용 화면)

`.py`/`.bat`/단가표가 섞여 있는 실제 작업 폴더를 그대로 보여주는 대신,
그녀가 볼 폴더 4개만 따로 모아둔다. `발주서_관리_바로가기_만들기.ps1`
(poonglim-code 보관)을 한 번 실행하면 자동으로 만들어진다.

```text
Z:\★풍림전자 사무 자동화\발주서 관리\
  ├── 1_발주총괄_여기에_넣기        (바로가기 → 매입처 관리\1단계\원본\)
  ├── 2_발주서_여기서_받기          (바로가기 → 매입처 관리\2단계\완료\)
  ├── 3_캐리어회신_여기에_넣기      (바로가기 → 매입처 관리\3단계\원본\)
  └── 확인이_필요합니다             (실제 폴더 — 이상 있을 때 여기로만 남김)
```

실제 폴더 구조나 스크립트 경로는 전혀 건드리지 않는다. 바로가기만 추가하는
방식이라 언제든 지워도 기존 자동화에 영향이 없다.

---

## 4. 설치 절차

1. `발주서_관리_바로가기_만들기.ps1`을 `Z:\★풍림전자 사무 자동화\`에 두고
   우클릭 → "PowerShell로 실행" (한 번만)
2. `풍림_발주자동화_워처.py`를 아무 폴더에나 둔다 (예: `매입처 관리\워처\`)
3. `캐리어_발주원장_검증.py`를 `1단계_발주원장구글시트업로드\` 폴더 안에
   `매입처발주.py`와 나란히 둔다
4. Windows 환경변수에 `ANTHROPIC_API_KEY` 등록 (선택 — 없으면 AI 체크만 생략)
5. 콘솔에서 `풍림_발주자동화_워처.py`를 손으로 한 번 실행해 로그 확인
6. 문제 없으면 Windows 작업 스케줄러에 등록 — 트리거: 매일, 08:00부터
   5분 간격 반복, 동작: `python 풍림_발주자동화_워처.py`

---

## 5. 확인 방법 (알람 없이)

- **정상 처리된 날**: 워처 자신의 `logs\날짜.log`에 조용히 기록만 남는다.
  발주서는 `발주서 관리\2_발주서_여기서_받기\` 안에 그날 날짜 폴더로
  생성되어 있으니 그걸 열어서 캐리어에 이메일 발송하면 된다.
- **이상이 있었던 경우**: `발주서 관리\확인이_필요합니다\` 폴더에
  `확인필요_....txt` 파일이 생긴다. 사유와 로그 일부가 적혀 있다. 확인
  후 조치하고 그 파일은 지우면 된다.
